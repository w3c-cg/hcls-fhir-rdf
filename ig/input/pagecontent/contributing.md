Contributions to this guide are welcome, including corrections, reproducible
examples, tool evaluations, and reports of implementation experience.

### Join the discussion

Join the RDF sub-group's weekly meetings. Ask in the
[#rdf channel on FHIR Chat](https://chat.fhir.org/#narrow/stream/179282-rdf)
for the current meeting schedule and joining details. The
[#ontology channel](https://chat.fhir.org/#narrow/stream/180812-ontology)
is also a place to discuss ontology modeling and reasoning.

### Propose a change

Submit an issue or pull request to the guide's GitHub repository. Its public
repository URL is pending confirmation; until it is available, discuss proposed
changes in the RDF channel.

For a query or conversion example, include the FHIR release, graph
representation, tool and version, minimal input data, expected results, and
known limitations. Use synthetic or appropriately de-identified examples;
do not submit patient-identifying information.

Edit the Markdown source in `input/pagecontent`, not generated HTML. Keep
downloadable queries in `input/artifacts`. Run `./scripts/build-preview.sh`
for a quick authoring check and `./scripts/_genonce.sh` for Publisher validation
before submitting a change. Include relevant validation findings in the pull
request.
