This implementation guide does not contain any custom FHIR profiles or extensions.
The FHIR package it builds includes SPARQL queries and other, optional FHIR RDF-related artifacts like ShEx schemas and OWL ontologies.

### Pre-processing SPARQL queries

[SPARQL Query Artifacts](query-artifacts.html) includes downloadable SPARQL queries/updates that can be used to pre-process FHIR RDF data to make it easier to query and reason over.

### FHIR RDF version artifacts

FHIR ShEx schemas and FHIR OWL ontologies, and extensions of both, for each FHIR version will be provided, including corrections to earlier versions.
